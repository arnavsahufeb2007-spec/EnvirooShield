# Portfolio Project: EnviroShield

**Developer:** Arnav Sahu  
**Focus:** AI/ML, environmental data, web development  
**Project repository:** [EnvirooShield](https://github.com/arnavsahufeb2007-spec/EnvirooShield)

## Project overview
EnviroShield explores how air-quality and weather information can be presented in a practical, accessible dashboard. The repository documents an environmental intelligence interface with air-quality metrics, forecasts, and decision-support features.

## Technologies documented in this repository
- React, TypeScript, Vite and Tailwind CSS
- Open-Meteo and atmospheric data sources
- Environmental data visualization and user-facing dashboards

## What this project demonstrates
- Building a data-driven web interface
- Working with external environmental datasets and APIs
- Organizing complex information into understandable UI components
- Exploring how forecasts and environmental indicators can inform decisions
